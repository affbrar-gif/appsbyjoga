# appsbyjoga: privacy & support pages for all apps

Live at **https://demobyjoga.online** (free hosting with GitHub Pages).

| App | Privacy Policy URL | Support URL |
|---|---|---|
| CleanWave | https://demobyjoga.online/cleanwave/privacy/ | https://demobyjoga.online/cleanwave/support/ |

## Add a new app
1. Copy the `template` folder and rename the copy (for example `replaycam`).
2. In both files, replace `APP NAME` and `app-folder`, then edit the text so it is true for that app.
3. Add a card for the app on `index.html`.
4. Commit. The site updates in about 1 minute.
5. Put the two links in App Store Connect.

If an app already has a privacy page somewhere else, use `template/redirect.html` instead.

## Files
- `CNAME`: the custom domain (do not delete)
- `style.css`: one shared style for all pages
